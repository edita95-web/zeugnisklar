„Zu unserer vollen Zufriedenheit“ – welche Note ist das?

Kurze Antwort: Meist eine 3 (befriedigend). Klingt gut, ist aber Durchschnitt.

Warum klingt eine 3 so positiv?

Arbeitszeugnisse müssen wohlwollend formuliert sein. Deshalb wird die Note über Steigerungen ausgedrückt: „Zufriedenheit“ → „volle Zufriedenheit“ → „vollste Zufriedenheit“, jeweils mit oder ohne „stets“.

FormulierungNote
stets zu unserer vollsten Zufriedenheit1
stets zu unserer vollen Zufriedenheit2
zu unserer vollen Zufriedenheit3
zu unserer Zufriedenheit4

Gilt das immer?

Nein, die Gesamtnote ergibt sich aus dem ganzen Zeugnis. Wenn die Aufgaben sehr positiv beschrieben werden und die Schlussformel vollständig ist, kann ein Zeugnis insgesamt besser wirken. Umgekehrt können versteckte Codes eine gute Formel abschwächen.

Kann ich eine 2 verlangen?

Nach der Rechtsprechung in Deutschland gilt die 3 als „durchschnittlich“. Wer eine bessere Note will, muss im Streitfall meist selbst darlegen, warum die Leistung besser war. Viele Arbeitgeber ändern die Formulierung aber auf eine höfliche Bitte hin, besonders wenn es keinen Streit gab. Einen Musterbrief finden Sie hier.
